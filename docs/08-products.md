## FAQ

**واش يقدر يلبس تحت الملابس؟**  
نعم، التصميم خفيف ويمكن لبسه تحت قميص واسع أو فوق الملابس.

**واش يعالج ألم الظهر؟**  
هو منتج دعم وراحة يومية، وليس علاجاً طبياً. إذا كان الألم قوياً أو مستمراً، استشر مختصاً.

**واش المقاس مناسب؟**  
الحزام قابل للتعديل ومناسب لأغلب الأجسام. ضع جدول مقاسات إذا توفر من المورد.

**واش يحتاج كهرباء أو شحن؟**

## 2. Product Data Shape

ينبغي تحويل البيانات إلى هذا الشكل:

```ts
export type Product = {
  id: string;
  slug: string;
  nameAr: string;
  nameEn: string;
  shortName: string;
  type: string;
  problem: string;
  price: number;
  upsellPrice: number;
  currency: "MAD";
  mechanism: string;
  headline: string;
  subheadline: string;
  bullets: string[];
  images: string[];
  faqs: { question: string; answer: string }[];
  crossSellPriority: string[];
};
```

---

## 3. Bundle Logic

لا تعرض تخفيضات bundle في v1. يمكن عرضها لاحقاً بعد إثبات الطلبات.

في v1:

- كل منتج بثمنه الكامل.
- cross-sells بثمنها الكامل.
- upsell فقط بعد checkout form وبثمن مخفض.

---

## 4. Required Product Page Proof Blocks

كل PDP يجب أن يحتوي:

- `TrustStrip`: COD، تأكيد قبل الإرسال، توصيل داخل المغرب.
- `MechanismBlock`: الآلية الفريدة.
- `MaterialsBlock`: المواد/التقنية.
- `HowToUse`: 3 خطوات.
- `Reviews`: 3 مراجعات.
- `FAQ`: 4-6 أسئلة.
- `CrossSell`: المنتجين الآخرين.
