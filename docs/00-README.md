## 4. مبادئ غير قابلة للتفاوض (Non‑negotiables)

1. **Mobile‑first**: أكثر من 90% من الزوار من الهاتف. كل شيء يُصمَّم للهاتف أولاً.
2. **RTL أصيل**: التخطيط، الأيقونات، الاتجاهات، الـpaddings — كلها RTL وليست مقلوبة LTR.
3. **سرعة قصوى**: LCP < 2.5s على 4G، صور WebP/AVIF، lazy‑load، لا مكتبات ثقيلة بلا داعي.
4. **لا صفحة سلة (`/cart`)** — فقط **Cart Drawer** ينزلق من الجانب في كل الموقع.
5. **الأثمنة المعروضة هي النهائية.** التخفيض الوحيد يظهر **بعد** إدخال الاسم والهاتف (Upsell بعد الفورم). الـCross‑sells دائماً بالثمن الكامل.
6. **الثقة قبل البيع**: كل ادّعاء مدعوم بدليل (علم/شهادة/مراجعة/ضمان). لا ادّعاءات طبية ممنوعة (انظر قواعد الإعلانات في 06).
7. **تأكيد الطلب بشري وسريع** يتم عبر لوحة الأدمين/التصدير (لكن الموقع نفسه COD فقط بدون واتساب/SMS في النسخة الأولى).
